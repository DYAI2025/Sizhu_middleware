# Example: GoalForge Objective

```markdown
# GoalForge Objective

## Goal
Create an evidence-labeled middleware architecture brief for the supplied CRM-to-ERP integration before implementation.

## Scope
- Identify consumers, producers, contracts, security, reliability, observability, and tests.
- Produce a gap matrix for missing artifacts.

## Non-goals
- No production code.
- No external API calls.

## Hard constraints
- Do not invent endpoints, schemas, auth behavior, rate limits, or runtime metrics.

## Acceptance criteria
- [ ] Evidence Ledger labels all material claims.
- [ ] Gap Matrix lists missing contract, auth, idempotency, observability, and test facts.
- [ ] Architecture Brief follows the declared output contract.

## Definition of done
- Brief, Evidence Ledger, and Gap Matrix are produced.
- Remaining MISSING/SOURCE_NEEDED items are listed.
```
